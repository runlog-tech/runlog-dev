Task: for each file matching `scripts/*/script.md` (one folder level deep) report (a) its title: the first line starting with `# `, without the `# `, and (b) its status: the first line within the first 40 lines that starts with `Status:` (ignore leading `**`, `>`, `_` and spaces; case-insensitive), first 60 characters after the colon, or `none` if there is no such line. Method: one Grep for the title lines and one Grep for the status lines across the files, first match per file (`-m 1`); do not read files in full. Return format: one line per folder, `folder | title | status`, sorted by folder, then `total: N`.
