# DESIGN.md — Systems Engineer Portfolio

## Palette
Monochrome. Off-white paper `#FAFAF7` background, near-black `#1A1A18`
text, one muted forest-green `#3F5D48` accent used only for links and
one underline rule. No dark mode toggle needed, no gradient anywhere.

## Layout
Reads like a long-form technical paper, not a "creative portfolio."
Single column, generous line-length limit (~68ch), section breaks are a
thin horizontal rule plus a short label in small-caps, not a numbered
eyebrow badge. No card grid at all, anywhere on the page.

## Motion
None. This is a résumé-adjacent page for people evaluating technical
credibility — motion would undercut that, not add to it.

## Voice
First person, terse, specific. "I wrote the Raft leader-election path
for our storage layer" beats "passionate about distributed systems."
Cite real numbers (throughput, latency, node counts) instead of
adjectives like "scalable" or "robust."

## Never
No middle-dot-separated tech stack lists (`Raft · Go · Rust`) — write
tech stack as a real sentence instead. No rotated/vertical section
labels. No "0.1 — INDEX" style numbered eyebrows.
